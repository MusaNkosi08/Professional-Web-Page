# Professional-Web-Page

This project is a futuristic personal profile webpage built with pure HTML and CSS. It serves as an interactive digital resume and portfolio for Musa Banathi Nkosi, a Digital Web Developer based in Cape Town, South Africa.

The page showcases a candidate introduction, technical skills, interests, professional experience, education, certifications, and contact information. It also includes direct links to GitHub and LinkedIn profiles.

The design uses a dark, high-tech aesthetic with glassmorphism panels, neon cyan and magenta accents, animated scan lines, and subtle glitch effects. It is fully responsive and works across desktop, tablet, and mobile devices.

Key sections include a profile card with a professional summary, a skills and interests panel, an experience and education timeline, a certifications badge list, and a contact card with clickable email, phone, GitHub, and LinkedIn links. All content is based on the candidate's real CV.

Technologies used are HTML5, CSS3, Google Fonts (Space Grotesk and Syne), and Font Awesome icons. No JavaScript or external frameworks are required. The file is self-contained and runs directly in any modern browser.

To view it, simply download or clone the repository and open the HTML file in your browser. No build steps or dependencies are needed.

This project was created to demonstrate front-end development skills, attention to detail, and the ability to design and build a polished, production-ready personal webpage from scratch.
